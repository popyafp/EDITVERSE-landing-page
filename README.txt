EDITVERSE — Landing Page

CARA MENJALANKAN
1. Ekstrak file ZIP.
2. Buka folder EDITVERSE-landing-page di Visual Studio Code.
3. Buka file index.html.
4. Klik kanan pada index.html lalu pilih "Open with Live Server" (jika ekstensi Live Server sudah terpasang).
   Alternatif: klik dua kali index.html untuk membukanya di browser.

STRUKTUR
- index.html : struktur dan isi landing page
- style.css  : seluruh tampilan, warna, layout, dan responsivitas
- script.js  : menu mobile dan tautan WhatsApp

YANG PERLU DIGANTI SEBELUM DIPAKAI
- Buka script.js, cari 6281234567890, lalu ganti dengan nomor WhatsApp bisnis kamu.
- Harga pada bagian Pricing masih berupa simulasi untuk tugas.
- Portfolio saat ini berupa visual konsep CSS, ganti dengan hasil edit asli ketika sudah tersedia.
- Produk aplikasi premium hanya boleh ditawarkan melalui jalur resmi dan sesuai ketentuan penyedia.

CATATAN
Font Google Fonts membutuhkan koneksi internet. Jika tidak ada internet, website tetap berjalan dengan font cadangan.
